# TouchFreeze

TouchFreeze is a lightweight Windows utility that automatically disables your laptop's touchpad while typing, preventing accidental palm touches and unwanted cursor jumps.

## Features

- **Smart Typing Protection**: Automatically temporarily freezes touchpad clicks and cursor movements while typing on the keyboard.
- **Smart Palm Rejection**: Distinguishes accidental palm touches from intentional single-finger cursor movements.
- **Touchpad Right Drag Zone**: Easy right-click dragging using a designated physical touchpad area (e.g., Right 1/3 or Bottom-Right).
- **System Tray Resident**: Runs silently in the background with minimal memory and CPU footprint.
- **Input Monitor**: Includes a built-in diagnostic view to test your touchpad sensitivity and touch inputs in real time.

## System Requirements

- **OS**: Windows 10 / Windows 11
- **Hardware**: Laptop with standard Touchpad or Windows Precision Touchpad (PTP)

## Installation

1. Download `TouchFreeze.msi` or `TouchFreeze.zip` from the [Releases Page](https://github.com/kuwa72/touchfreeze/releases).
2. Install or extract the files.
3. Launch TouchFreeze. It will appear as an icon in your system tray (notification area).

## Usage

TouchFreeze works automatically in the background.

Right-click the **TouchFreeze** icon in the system tray for settings:

- **Auto Start**: Start TouchFreeze automatically when Windows boots.
- **Block Time**: Adjust typing freeze duration (`Fast 300ms`, `Normal 500ms`, `Slow 700ms`).
- **Palm Rejection**: Enable or disable single-finger motion permission during typing.
- **Right Drag Zone**: Select the physical touchpad area for right-click drag operations.
- **Input Monitor...**: Open the real-time diagnostic window to inspect touchpad touch points.
